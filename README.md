### WEEK-2

This folder contains JavaScript programs to practice arrays, objects, classes, conditions, modules, and real-world logic examples.

---

# Files and Tasks

### bankadv.js
Creates a simple bank transaction system.  
Shows account transactions and balance details.

### classDemo.js
Demonstrates how classes and objects work in JavaScript.  
Shows object creation using constructors.

### ctrl1.js
Uses conditions to check profile completion status.  
Practices simple if-else logic.

### ctrl2.js
Applies discount rules based on product price.  
Practices conditional statements.

### ctrl3.js
Checks different completion conditions using boolean values.  
Helps understand logical operations.

### deepcopy.js
Shows how deep copy works in objects.  
Changes in copied objects do not affect the original object.

### shallowcopy.js
Shows shallow copy behavior in objects.  
Changing nested values can affect the original object.

### fruit.js
Performs operations on fruit arrays.  
Practices array handling and printing values.

### movieadv.js
Creates a movie recommendation example using arrays and objects.  
Practices filtering and displaying movie data.

### onlinecourse.js
Works with a list of online courses.  
Uses array methods like filtering and checking values.

### otp.js
Creates a simple OTP timer/countdown program.  
Practices timing logic.

### payrolladv.js
Manages employee salary and payroll details.  
Uses objects and calculations.

### performance_studadv.js
Stores and checks student performance data.  
Works with marks and conditions.

### shoppingadv.js
Builds a small shopping/cart example.  
Handles products, prices, and totals.

### studentmark.js
Stores student marks and performs basic calculations.  
Practices arrays and object handling.

### temp.js
Simple practice file for testing JavaScript concepts.

### timer.js
Creates a basic timer using JavaScript.  
Practices countdown or interval functions.

### userobj.js
Stores and displays user information using objects.
